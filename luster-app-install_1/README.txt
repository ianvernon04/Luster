Luster demo — installable build

This folder is the whole app. Host it on any static site (Netlify, Vercel, GitHub Pages, Cloudflare Pages)
and open the URL on the device:

  iPhone / iPad (Safari):  Share → Add to Home Screen → "Luster" appears as a full-screen app, works offline.
  Android (Chrome):        menu → Install app (or the install banner).
  Mac / PC (Chrome/Edge):  the install icon in the address bar.

Fastest hosting: app.netlify.com/drop → drag this folder → you get https://<name>.netlify.app in ~10 seconds.
All data stays on the device (IndexedDB). Nothing is sent anywhere. Payments and texting are simulated.
